# ZOM-B-GONE — Captcha Reimagined
Plain HTML/CSS/JS. No install, no npm, no extensions.
## Run
Open the folder in VS Code and double-click `index.html` (or right-click → Open with Browser).
## Story
L1 Addition: defeat zombies to hit the exact target (5–20) and open the cell.
L2 Multiplication: the product (e.g. 3×4=12) is the exact energy total needed to turn the light green.
L3 Subtraction: the difference (e.g. 17−8) is the exact total needed to unlock the door.
18s timer per level; overshoot or timeout = FAIL → TRY AGAIN / RESTART GAME (no reload).
Keys: Tab+Enter, or 1–9 to hit zombies. Mute button bottom-right.
